# forcursor

## Thai Learn — iPhone app + home/lock‑screen widget

A personal iPhone app that teaches Thai and shows random Thai words on your
Home Screen / Lock Screen (via a widget) with English + Hindi pronunciation and
English + Hindi meaning.

👉 The app lives in [`ThaiWallpaperLearn/`](ThaiWallpaperLearn/). See
[`ThaiWallpaperLearn/README.md`](ThaiWallpaperLearn/README.md) for how to build
and run it (needs a Mac with Xcode) and how to add the widget to your screen.
